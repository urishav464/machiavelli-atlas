# כלים לאטלס

| כלי | מה הוא עושה |
|---|---|
| `setup.sh` | מתקין ספריות Python ומוריד את Leaflet למטמון (`~/.atlas-cache`) |
| `sources/get_sources.sh` | מוריד מקורות עתיקים מ-Perseus (ליוויוס, דיוניסיוס, פלוטרכוס, או כל יצירה לפי מזהה) ואת מאגר פליאדס |
| `sources/extract.py` | הופך TEI של Perseus לשורה לכל סעיף: `ספר.פרק.סעיף טקסט` |
| `sources/pleiades.py` | מחפש מקום עתיק: מזהה, קואורדינטות, רמת דיוק, תיאור |
| `terrain/get_dem.sh` | מוריד גבהים (SRTM) ומקווי מים (ASTER WBD) מ-GitHub |
| `terrain/tiles.py` | אריחי תבליט מפורטים לאזור, משתלבים בצבעי מפת הבסיס |
| `terrain/rivers.py` | משרטט נהרות לפי זרימת המים, ובודק אותם מול נקודות ידועות |
| `terrain/latium-rivers.json` | הטיבר והאניו, אחרי בדיקה |
| `overlays/lib.py` | ספריית שכבות השטחים: תפקידים, צבעים, קווקוו, אזורים רכים, גאומטריה ללחיצה |
| `overlays/rome_kings.py` | דוגמה מלאה: ארבעת המלכים של רומא |
| `test/serve.sh` | מריץ עותק בדיקה מקומי של האתר |
| `test/shots.js` | צילומי טלפון של כל צעד ושל כל כרטיס בסיפור |

הסדר והכללים: `AGENTS.md` בשורש ה-repo.
